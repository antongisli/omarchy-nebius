# Brand assets

The Nebius logo and symbol are sourced from Nebius's public website on September 11, 2026:

- `nebius-logo.svg`: https://nebius.com/logo.svg
- `nebius-icon.svg`: https://nebius.com/favicon/favicon.svg

The source files are preserved as supplied. The wordmark uses lime `#E0FF4F`; the symbol uses `#DAFF33` and blue `#052B42`. Plugin controls use the wordmark lime with blue ink. Terminals use the nearest practical 256-color equivalents, without modifying terminal palette slots.

Nebius names and marks belong to their respective owners and are not relicensed by this repository's MIT code license. This repository is maintained by Anton Smith.

`preview.png` and documentation previews are rendered from the plugin's real QML and terminal drawing code with explicitly synthetic data. They contain no account or resource screenshots. See `tools/render_preview.py` and `tools/preview.qml` for the source.
