# Brand assets

The Nebius logo and symbol are sourced from Nebius's public website on September 11, 2026:

- `nebius-logo.svg`: https://nebius.com/logo.svg
- `nebius-icon.svg`: https://nebius.com/favicon/favicon.svg

The source files are preserved as supplied. The wordmark uses lime `#E0FF4F`; the symbol uses `#DAFF33` and blue `#052B42`. Plugin controls use the wordmark lime with blue ink. Terminals use the nearest practical 256-color equivalents, without modifying terminal palette slots.

Nebius names and marks belong to their respective owners and are not relicensed by this repository's MIT code license. This is an unofficial community plugin maintained by Anton Smith, not a supported Nebius product.

`preview.png` and the terminal screens in `docs/screenshots/` are rendered from the plugin's production terminal drawing code with explicitly synthetic data. The optional native launcher capture uses the real QML. They contain no account or resource screenshots. See `tools/capture-previews`, `tools/render_preview.py`, `tools/preview.qml` and `tools/terminal-capture.qml` for the source and reproducible offscreen capture workflow.
